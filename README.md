"MOSAREST" — мой 4й проект на 1 курсе УвКИ. Компания представляет из себя Подмосковный домик, в который уставшие от городской суеты люди приезжают, чтобы отдохнуть и пособирать мозаику.

Проект написан на HTML, CSS, JS

Использование нейросетей
1. Мозаичный конструктор (DeepSeek)
Задача:
Сделать интерактивную сетку 14×13, где пользователь может рисовать фигуры (квадрат, треугольник, ромб, круг) разными цветами, с кнопками очистки, случайной генерации, завершения дизайна и корзиной.

Примерный промпт:
«Напиши модульный JavaScript для конструктора мозаики. сетка 14×13, 4 паттерна (square, triangle, diamond, circle), 5 цветов по моей картинке. Реализуй рисование по клику/перетаскиванию, кнопки "Очистить", "Случайно", "Закончено", "Корзина". Логика: корзина активна только после нажатия "Закончено", чистый JS.»

Результат:
Полноценный конструктор в mosaic.js с полным циклом:
рисование → сохранение → блокировка/разблокировка кнопок → подтверждение.

2. Анимация перехода между страницами (DeepSeek)
Задача:
При клике на ссылку страница заполняется цветными плитками c левого верхнего края, затем происходит переход. На новой странице плитки исчезают в обратном порядке.

Примерный промпт:
«Сделай плавный переход между страницами: при клике на ссылку экран заполняется квадратными плитками волной от левого верхнего края, затем происходит переход. На новой странице плитки исчезают в обратном порядке. Используй canvas и requestAnimationFrame»

Результат:
Готовые функции leave() и enter() с плавной волновой анимацией.

3. Аккордеон с переключением фото (DeepSeek)
Задача:
При открытии элемента аккордеона менять активное фото справа.

4. Маска-текст с градиентом для секций (Claude Sonnet 4.6)
Задача:
Текст вырезается из белого прямоугольника, поверх накладываются световые градиенты (блики), размер и прозрачность меняются при скролле.

Примерный промпт:

«Сделай на Canvas маску: текст "MOSAREST" вырезается из белого прямоугольника, на него накладываются 3 градиента (блики). Размер шрифта и прозрачность зависят от скролла. Используй destination-out, плавный lerp, easing-функции.»

Результат:
Эффектный текст с динамическими бликами, который проявляется при скролле.

5. Появление элементов на старнице 404 (Claude Sonnet 4.6)
Задача: сделать плавное появление всех элементов, которые выстраиваются в цифры 404.
